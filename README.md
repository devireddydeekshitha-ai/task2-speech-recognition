# Speech Recognition System

## Overview

This project converts speech into text using pre-trained speech recognition models.

## Technologies Used

- Python
- SpeechRecognition
- Google Speech API

## Installation

```bash
pip install SpeechRecognition
```

## Run

```bash
python speech_to_text.py
```

## Input

Audio File (.wav)

## Output

Text transcription of speech.

## Sample Audio

The audio file used for speech recognition is included in this repository as `sample_audio.wav`.

If GitHub does not play the audio directly, click **View Raw** to download and listen to the file.
